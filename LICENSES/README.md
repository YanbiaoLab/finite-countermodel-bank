# License registry

The repository's primary license is the Apache License, Version 2.0; its exact text
is in the root [`LICENSE`](../LICENSE) file. It applies to material for which the
project contributors hold the necessary rights. It does not override a
source-specific license or turn an unconfirmed rights status into a license grant.

This directory is a registry location for future source-specific license texts and
notices. This README summarizes license scope but is not itself a license grant.

When a later reproduction stage introduces material governed by a third-party
license, add the exact license or notice here, link it from that stage's manifest,
and retain the original attribution. Material whose rights status has not been
confirmed must use `license_status: "not-specified"` in its source record.
